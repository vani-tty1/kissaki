## Description

> !NOTE: Still under development and has no clear direction as of writing this README

The goal is to create a text editor like `gnome-text-editor`
but with a built in terminal like `zed` but not as heavy as
GNOME Builder.


## Building

Right now its still a bit in kinda like alpha stage but you
can clone this repo and open in GNOME Builder and the IDE 
will auto install all deps based on the manifest.
